Lampiran E — Lampiran: Menjalankan dan Mengembangkan Buku

E.1 Persyaratan

Instal Quarto dari quarto.org. Proyek ini menggunakan format buku bawaan Quarto; tidak memerlukan ekstensi eksternal untuk HTML maupun EPUB. Dokumen .qmd, aset gambar, CSS, serta file pengaturan disertakan.

E.2 Render

Dari folder proyek:

quarto preview
quarto render --to html
quarto render --to epub
quarto render --to typst

PDF edisi ini dibuat melalui quarto render --to typst, menggunakan mesin Typst bawaan Quarto. Alternatif LaTeX tersedia melalui quarto render --to pdf jika sistem menyediakan XeLaTeX. Diagram buku memakai aset vektor SVG/PDF dengan sumber Mermaid dan DOT yang dapat diedit di images/diagrams/, sehingga hasil cetak tidak memerlukan proses screenshot browser.

E.3 Pilihan ekstensi

Tautan katalog ekstensi format yang menjadi awal permintaan adalah Quarto Extensions — Custom Formats. Beberapa ekstensi memiliki dukungan untuk buku, tetapi memerlukan instalasi, kompatibilitas versi dan lisensi yang perlu diperiksa. Edisi ini memilih buku bawaan agar portabel. Setelah instalasi Quarto tersedia, pembaca dapat mengganti tema atau memasang ekstensi dengan mengikuti petunjuk masing-masing.

E.5 Infografik

Seluruh gambar infografik Tema 0–6 disertakan sebagai PNG dan diletakkan pada awal pembahasan masing-masing tema. Gambar dibuat sebagai alat bantu komunikasi; angka, label, serta hubungan dalam infografik perlu diperiksa terhadap naskah bila digunakan untuk pengajaran formal.

E.6 Integritas data dan versi

Jangan membagikan dataset yang tidak diizinkan lisensinya. Simpan sumber data, versi, tanggal unduh, langkah transformasi, dan konfigurasi analisis; untuk publikasi ilmiah, pisahkan ilustrasi atau data simulasi dari hasil pengukuran nyata.

E.7 Pemeriksaan sebelum membagikan hasil render

Periksa daftar isi, tautan antarbab, tampilan rumus, lebar tabel, keterangan gambar, dan bibliografi pada format yang akan dibagikan. HTML yang terlihat baik belum menjamin PDF mempunyai pemenggalan halaman yang baik. Setelah mengubah isi, bangun ulang format keluaran agar pembaca tidak menerima versi lama.

Contoh Python di buku ditandai eval: false ketika merupakan pola yang membutuhkan input atau penyesuaian. Status itu berarti kode ditampilkan dan tidak dijalankan oleh Quarto; jangan menafsirkan hasil render sebagai bukti eksekusi analisis dataset. Jika contoh akan dijalankan, siapkan data yang sah, dependensi, dan pemeriksaan hasil secara terpisah.

E.8 Menambah bab tanpa memutus keterlacakan

Buat sumber .qmd, daftarkan pada _quarto.yml, lalu gunakan ID gambar dan kunci sitasi yang unik. Tambahkan metadata sumber pada references.bib dan sitasi pada klaim yang memerlukannya. Jangan menambahkan daftar pustaka yang tidak terkait pembahasan hanya untuk memperpanjang referensi.

Saat merevisi angka contoh, periksa seluruh tempat pemakaiannya: narasi, persamaan, tabel, soal, dan kunci. Simpan catatan perubahan yang memengaruhi hasil atau penafsiran. Pemeliharaan buku merupakan bagian dari mutu ilmiah karena pembaca perlu mengetahui bahwa contoh dan bukti tetap selaras pada versi yang dibagikan.
